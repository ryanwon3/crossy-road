This is CrossRoad built in under 4 hours using various AI tools. The main differences are the graphics and the viewpoint the game is in (straight up instead of diagonal). You play by using wasd or arrow keys to move forwards / sideways. You want to make it as far as possible without getting hit by a car or drowning. I've used both the various models on kiro auto and codex 5.6 sol. I used kiro to create most of the game, and then polished / bugfixed with codex.
